# แท่นวางสไลด์และยึดกล้อง (แบบร่าง v1)

โมเดลสร้างจาก `rig_cad.py` (CadQuery) ขนาดฐาน กรอบ และขีดอ่านจาก `configs/synth.yaml` (`scene.pla_base`) จึงตรงกับภาพจำลองที่ใช้เทรนและทดสอบ ส่วนอื่นปรับได้ที่ `RIG` ในไฟล์เดียวกัน

```bash
~/cadenv/bin/python hardware/rig_cad.py --out hardware/out      # STEP + STL
~/cadenv/bin/python hardware/render_rig.py --out hardware/out   # ภาพ preview (PNG, ไม่ commit)
```

ติดตั้งครั้งแรก (WSL): `python3 -m venv ~/cadenv && ~/cadenv/bin/pip install cadquery pyyaml matplotlib`

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `out/step/slide_rig_assembly.step` | ทั้งชุดรวมกัน (มีกล้องจำลองไว้ดูสัดส่วน) |
| `out/step/<part>.step` | แยกชิ้น สำหรับเปิดใน SolidWorks |
| `out/stl/<part>.stl` | ชิ้นที่พิมพ์ 3D (ไม่มีเสาอะลูมิเนียม เพราะเป็นของซื้อ) |

**SolidWorks:** ไม่มีไฟล์ `.SLDPRT`/`.SLDASM` โดยตรง เพราะต้องใช้โปรแกรม SolidWorks สร้าง ให้เปิด `.step` ใน SolidWorks (File → Open → เลือกชนิด STEP) แล้ว Save As เป็น `.SLDPRT` หรือ `.SLDASM` ได้เลย ถ้าต้องการ feature tree ที่แก้ได้ ใช้ FeatureWorks → Recognize Features (มีใน SolidWorks Professional/Premium)

## การพิมพ์

- PLA ชั้น 0.2 มม. ผนัง 4 ชั้น infill 30% gyroid
- ฐานพิมพ์หงายหน้าขึ้น (ร่องกรอบอยู่ด้านบน) ซีกซ้าย 210 มม. ใส่ฐานพิมพ์ 256 มม. ได้
- carriage พิมพ์คว่ำ (ด้านแขนลงฐาน) จะได้ไม่ต้องใช้ support ใต้แขน
- น็อตทุกตัวใส่ช่องหกเหลี่ยมจากด้านล่างฐาน

## ประกอบ

1. ต่อสองซีกฐานด้วย M4 × 6 สองตัวที่ลิ้นต่อ
2. วาง bracket ให้ปีกด้านหน้าทับแถบหลังของฐาน ขัน M4 × 14 สี่ตัว
3. เสียบเสา 2020 ลงช่องของ bracket ขัน M5 × 25 จากด้านล่าง
4. ใส่ heat-set insert ที่ carriage สวมลงเสา ล็อกด้วยสกรูมือหมุน
5. ยึดกล้องด้วยสกรู 1/4"-20 ผ่านร่องที่ปลายแขน ร่องยาว 40 มม. เลื่อนให้เลนส์อยู่ตรงกลางกรอบได้

## เหตุผลที่ออกแบบแบบนี้ (มาจากผลบนภาพจำลอง)

- **กล้องมองตรงลงกลางแถว:** ผลชุด rig อ่านได้ประมาณ 95% ส่วนภาพถ่ายถือมือได้ประมาณ 75%
- **ภาพต้องครอบ ≥ 320 มม. (กรอบ 300 + ขอบ 10 ต่อข้าง):** รหัสที่หลุดขอบภาพอ่านไม่ได้แม้รู้มุมที่ถูกต้อง
- **ความสูงเลนส์ = 160 / tan(HFOV/2):** HFOV 50° ได้ 343 มม., 65° ได้ 251 มม., 72° ได้ 220 มม. ยังไม่ได้เลือกกล้อง จึงให้ carriage เลื่อนได้ทั้งช่วง
- **ความละเอียด:** กล้อง 12MP ครอบ 320 มม. ได้ประมาณ 4.5 px/module ช่วงนี้อ่านได้ประมาณ 99% (ภาพจำลอง)
- **กล้องต้องขนานกับฐาน** และควรล็อกโฟกัสกับ exposure
- **แสง:** ฉลากและกระจกสะท้อนแสง ควรใช้ไฟ diffuse สองข้างทำมุมเฉียง ไม่ยิงตรงลงจากตำแหน่งกล้อง

## ข้อจำกัดของแบบร่างนี้

- ยังไม่ได้พิมพ์และประกอบจริง ค่าเผื่อ (0.3 มม.) อาจต้องปรับตามเครื่องพิมพ์
- แขนกล้องเป็น PLA ยื่น ~100 มม. เหมาะกับกล้องไม่เกินประมาณ 300 ก. ถ้ากล้องหนักกว่านี้ ให้เพิ่ม `arm_t` หรือเปลี่ยนแขนเป็นอะลูมิเนียม
- ยังไม่มีชิ้นยึดไฟ
- ตรวจแล้วว่าชิ้นส่วนไม่ชนกันใน assembly (ตรวจด้วย boolean intersect)

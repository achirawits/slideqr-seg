# Model comparison - SYNTHETIC test images only

All numbers come from synthetic renders; they are not real-photo results.

* Same split, input long side 1280 (RF-DETR 1272), 60 min wall-clock training budget each, seed 0.
* RF-DETR-Seg Nano runs ~25 min per epoch at 1272 px, so it got only 2 epochs in the budget; its numbers reflect the equal-time rule, not a converged model.
* **rfdetr_long** is a SUPPLEMENTARY run OUTSIDE the equal-time rule (up to 30 epochs, early stopping on validation); compare it with the others only as "what RF-DETR reaches when trained longer".
* warp, then crop = 4-corner warp first, axis-aligned crop only when the warp gives no read.
* Decoder for all three inputs: zxing-cpp, LocalAverage binarizer with GlobalHistogram fallback.
* **oracle** = ground-truth corners pushed through the same scoring: the ceiling for each ppm bin (and, in the corner-error column, the floor of the mask -> quad conversion).
